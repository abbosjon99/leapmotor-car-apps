HOW TO GO BACK
--------------
Remove one app:
  adb uninstall <package>

Patched app -> original:
  adb uninstall <package>
  adb install --install-reason 64 -r -g "C:\Users\user\Downloads\car-apks-320dpi\originals\<file>.apk"

Remove LP Companion (bubble, wheel buttons, its listener / overlay / accessibility access all go with it):
  adb uninstall uz.carhelper.passenger
  If the passenger sidebar was hidden at that moment, bring it back:
  adb shell am broadcast --user 10 -a com.leapmotor.iqiyi.action.nav.visibility --ei visibility 0

Screen density (already factory, only if ever changed again):
  adb shell wm density reset -d 0

If you ran the AppListData write and want it undone:
  adb push "C:\Users\user\Downloads\car-apks-320dpi\backup\AppListData-original.json" /data/local/tmp/pf.json
  adb shell 'service call system_files_service 2 s16 AppListData s16 "$(cat /data/local/tmp/pf.json)"'
  adb shell rm /data/local/tmp/pf.json
  adb shell settings put global cloudListUpdate 1

Car fully back to how it was:
  uninstall all 11 apps in the table above. Density is already 160.
  Nothing in the firmware or Leapmotor's own apps was modified.

LP Companion 2.9
  - Back stopped working after every car restart: the car drops the "LP Companion Back button"
    accessibility service on boot, and has no Accessibility settings screen to turn it back on.
  - Fix: new BackRepair. When the Back service isn't running, the app adds itself back to
    enabled_accessibility_services (keeps every other entry, e.g. the car's aispeech service).
    Checks every 10 s for 2 min after the bubble starts, then every 60 s. Tapping a grey Back
    also tries it right away.
  - Needs one ADB grant (new permission WRITE_SECURE_SETTINGS, survives restarts and updates):
      adb shell pm grant --user 10 uz.carhelper.passenger android.permission.WRITE_SECURE_SETTINGS
  - Grey Back button no longer opens Accessibility settings (the car has none); it shows a message.
  - Undo: adb shell pm revoke --user 10 uz.carhelper.passenger android.permission.WRITE_SECURE_SETTINGS
          and/or install LP Companion 2.8 again (adb install --install-reason 64 -r).

LP Companion 2.13
  - Second steering-wheel channel: com.leapmotor.steerwheelcontrol.media, int extra "action"
    1 = previous, 4 = next, 7 = play/pause (from DiPlay-Leapmotor's 2024-27 notes; it is also
    the broadcast the old YM Button used). Registered by the bubble service while it runs.
  - Both channels (METER.CTRL via the Migu bridge = "meter", steerwheelcontrol = "steer") share
    one 350 ms de-dup, so a press that arrives on both is handled once.
  - Voice commands (VOICE.CTRL) are not de-duplicated.
  - If a car source (radio, Bluetooth, Leapmotor apps) is playing and the sideloaded player
    isn't, a "steer" press is left to the car.
  - Test: adb logcat -s LPWheelKeys   then press prev / next / play-pause on the wheel.
    Each press logs its channel and "accepted" or "dropped (duplicate within 350 ms)".

  Undo any of these: install the previous APK (LP-Companion-2.9/2.10/2.11/2.12.apk) with -r.
