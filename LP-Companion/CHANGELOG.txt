HOW TO GO BACK
--------------
Remove one app:
  adb uninstall <package>

Patched app -> original:
  adb uninstall <package>
  adb install --install-reason 64 -r -g "C:\Users\user\Downloads\car-apks-320dpi\originals\<file>.apk"

Remove LP Companion (bubble, wheel buttons, its listener / overlay / accessibility access all go with it):
  adb uninstall uz.carhelper.passenger
  If the passenger sidebar was hidden at that moment, bring it back:
  adb shell am broadcast --user 10 -a com.leapmotor.iqiyi.action.nav.visibility --ei visibility 0

Screen density (already factory, only if ever changed again):
  adb shell wm density reset -d 0

If you ran the AppListData write and want it undone:
  adb push "C:\Users\user\Downloads\car-apks-320dpi\backup\AppListData-original.json" /data/local/tmp/pf.json
  adb shell 'service call system_files_service 2 s16 AppListData s16 "$(cat /data/local/tmp/pf.json)"'
  adb shell rm /data/local/tmp/pf.json
  adb shell settings put global cloudListUpdate 1

Car fully back to how it was:
  uninstall all 11 apps in the table above. Density is already 160.
  Nothing in the firmware or Leapmotor's own apps was modified.
